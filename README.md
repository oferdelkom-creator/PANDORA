# תיבת פנדורה

מיזם ללא מטרות רווח לקידום שוויון בגישה לצדק בישראל.

אי-השוויון בגישה לצדק אינו רק פער בייצוג — הוא פער בידע. אדם עם כסף
יודע שקיים סעד, יודע איך ההליך עובד, ויודע אם עורך הדין שלו עושה עבורו
עבודה. אדם בלי כסף לא יודע אף אחד משלושת הדברים.

**התוכנית המלאה:** [`docs/business-plan.md`](docs/business-plan.md)

## מבנה

```
packages/deadline-gate/   שער המועדים — מנוע כללים דטרמיניסטי
docs/                     התוכנית העסקית וחוב האימות המשפטי
```

`apps/web/` ייכנס כשה-MVP ייבנה (Next.js + Supabase, מובייל-first בעברית).

## מצב

| שלב | סטטוס |
|---|---|
| 0 — גיוס עורך הדין השותף | **פתוח. חוסם את כל השאר.** |
| 0 — הקמת העמותה | פתוח |
| 0 — מיפוי מועדים ועילות | הקוד כתוב, האימות המשפטי פתוח |
| 1 — MVP צר | לא התחיל |

**אף מסלול משפטי אינו מאומת.** כל תוצאה של המנוע חוזרת עם
`verification: 'unverified'`.
[`docs/legal-verification-backlog.md`](docs/legal-verification-backlog.md)
הוא ההעברה לעורך הדין השותף.

## פקודות

```
npm install
npm test        # 31 בדיקות
npm run typecheck
```

## שני כללים שלא נשברים

מסעיף 3 בתוכנית, והם נאכפים בקוד ולא רק במסמך:

1. **כנות לפני תקווה.** "אין מסלול" היא תשובה לגיטימית, והיא תהיה
   הנפוצה ביותר — ותמיד עם הסתעפות למה שכן פתוח.
2. **עוגן בלבד.** כל אזכור פסיקה חייב מקור אמיתי וקישור. פסק דין
   מומצא אחד שמגיע לשופט הורג את הפרויקט.
